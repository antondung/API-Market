# API Hub — thiết kế dùng chung

Consumer, Provider và Admin dùng cùng header, typography, spacing, button, input, panel và dialog. Sự khác nhau nằm ở menu, quyền và nội dung nghiệp vụ.

| Thành phần | Quy ước   |
| ---------- | --------- |
| Nền trang  | `#faf8ff` |
| Primary    | `#2a14b4` |
| Sidebar    | `#f2f3ff` |
| Chữ chính  | `#131b2e` |
| Viền       | `#c7c4d7` |
| Heading    | Geist     |
| Nội dung   | DM Sans   |

Desktop dùng sidebar 248px; mobile chuyển sidebar thành drawer. Form có label nhìn thấy được, focus ring, lỗi inline và trạng thái busy. Nội dung chưa có backend dùng trạng thái “chưa khả dụng”, không hiển thị số liệu hoặc thao tác giả.

Đây là baseline hiện tại để phát triển tiếp, chưa phải xác nhận thiết kế cuối của người dùng.
